# Roncray

A responsive premium product landing page built using HTML5 and CSS3.

## About

Roncray is a concept premium lifestyle brand featuring watches,
fragrances, accessories and leather goods.

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Features

- Responsive navigation
- Premium hero section
- Product collection
- Call-to-action
- Responsive product grid
- Mobile-friendly layout
- Footer with social links

## How to Run

1. Clone the repository.
2. Open `index.html` in a browser.
3. For development, use VS Code Live Server.
